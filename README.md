## Features

- **Pre‑written script templates** – for Logitech G‑Hub, Razer Synapse, and AutoHotkey.
- **Recoil pattern visualisation** – PNG charts for all major PUBG weapons.
- **Sensitivity curve editor** – interactive HTML tool to design custom response curves.
- **Weapon‑specific presets** – separate profiles for AR, DMR, SMG, and LMG.
- **Toggleable activation** – bind macros to mouse side buttons with LED feedback.
- **Delay and smoothing controls** – adjust interpolation for natural‑feel compensation.
- **Script annotation guide** – commented code explaining each parameter.
- **Safety timeout mechanism** – auto‑disables macro after 5 seconds of inactivity.
- **Comparison mode** – side‑by‑side recoil plots with/without compensation.
- **Backup & restore utility** – save your original mouse settings.

## Requirements

- Windows 10 / 11 (64‑bit)
- PUBG (Steam or official client)
- A programmable mouse or macro‑capable software (Logitech, Razer, AHK)

## Usage

1. Extract the files to a known location.
2. Open the folder corresponding to your macro software.
3. Import the `.lua`, `.xml`, or `.ahk` script as per your software's instructions.
4. Adjust in‑game sensitivity to match the reference values in `sensitivity_guide.txt`.
5. Test in training mode and fine‑tune the compensation multiplier.
6. Bind activation keys and set the timeout as desired.

## About the project

PUBG-Macro-Norecoil is an educational repository that demonstrates how scriptable peripherals can be configured to compensate for weapon recoil patterns. It provides commented source code, visual reference charts, and interactive tools to help users understand the relationship between mouse movement curves and in‑game weapon behaviour. All materials are intended for study and personal configuration experimentation.
